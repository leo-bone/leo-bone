# Leo

> **English** · [简体中文](#简体中文) · [Site](https://leo.uichain.org/) · [X](https://x.com/leo7_lau)

Investor, founder, and former university lecturer. I taught at a university, shipped products at a
Fortune 500, then started putting my own money behind my own calls and built a company.

I'm interested in one thing, really: **how to make the sentence "I think this will happen" cost
something.** Teaching made me explain things clearly. The corporate years showed me how many layers a
decision crosses before it reaches a production line. Investing put a number on every opinion.
Founding invoiced every lesson at once.

## What I'm working on

- **Valuation & macro, as runnable workflows** — not articles that end when you publish them, but
  skills that get re-run.
- **Brand & cross-border** — years in overseas tenders for medical devices turned out to be more
  useful than expected.
- **Crypto** — still on the list, one line on the list, not the whole page.

## Agent skills (open source)

| Skill | What it does |
|---|---|
| [valuation-comps](https://github.com/leo-bone/valuation-comps) | Trading comps in 8 steps. Peer screening, multiple alignment, quartiles — arithmetic lives in a tested script. |
| [dcf-quick](https://github.com/leo-bone/dcf-quick) | One-page DCF with a downside floor, and position size derived from the **worst case**, not the size of the opportunity. |
| [macro-dashboard](https://github.com/leo-bone/macro-dashboard) | Weekly four-variable regime switch (rates / credit / earnings / liquidity) with a hard-coded risk-off override. |

All three are stdlib-only Python with unit tests — the agent fetches data, the script does the math.
